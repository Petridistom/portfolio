Brokering Code with JavaScript

Part of my design process with writing code is to think of the ways of interacting that are meaningful for the user.

In this project, I was creating something for a community of practice, that being me and my girlfriend.
When at home we practice yoga and meditation, so to support this I created a script that would render a breathing ball, to aid in our meditation.

When designing on the web it can be useful to think of ways outside of the screen in which we can interact. The code is simple, and useful as a means to an end.
